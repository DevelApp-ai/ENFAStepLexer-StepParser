# ENFAStepLexer-StepParser

**A modern, high-performance lexical analysis and parsing system with
comprehensive PCRE2 support and CognitiveGraph integration**

[![CI](https://github.com/DevelApp-ai/ENFAStepLexer-StepParser/actions/workflows/ci.yml/badge.svg)](https://github.com/DevelApp-ai/ENFAStepLexer-StepParser/actions/workflows/ci.yml)
[![CD](https://github.com/DevelApp-ai/ENFAStepLexer-StepParser/actions/workflows/cd.yml/badge.svg)](https://github.com/DevelApp-ai/ENFAStepLexer-StepParser/actions/workflows/cd.yml)
[![NuGet StepLexer](https://img.shields.io/nuget/v/DevelApp.StepLexer.svg?label=DevelApp.StepLexer)](https://www.nuget.org/packages/DevelApp.StepLexer)
[![NuGet StepParser](https://img.shields.io/nuget/v/DevelApp.StepParser.svg?label=DevelApp.StepParser)](https://www.nuget.org/packages/DevelApp.StepParser)

The system consists of **DevelApp.StepLexer** for zero-copy tokenization and
**DevelApp.StepParser** for semantic analysis and grammar-based parsing.

For the full project overview, see the
[README](README) — this page is the documentation hub for the site.
